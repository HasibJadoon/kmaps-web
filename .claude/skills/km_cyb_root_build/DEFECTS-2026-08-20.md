# Instrument defects — audit session 2026-08-20

Cross-cutting audit, not a root build. Seven defects. The first is the one that matters.

## 1. TWO ROOT NODE SCOPES — both real, different questions
`CYB:quran:{surah}:{from}-{to}:root:{root}` (domain=quran, scale=piece) — 53 nodes, all sensed.
Asks: is this root ready FOR THIS PASSAGE?
`CYB:arabic:root:{root}` (domain=arabic, scale=root) — 1,642 nodes, 2 sensed.
Asks: how complete is this root IN THE LEXICON, independent of any passage.
NOT a duplicate and NOT dead: all 1,642 carry build_pct>0 (avg 32.7), states mined 1,456 /
seeded 168 / partial 17 / compiled 1, last written 2026-08-15. Deleting them would destroy
real build tracking. DO NOT RETIRE.
The two are distinguished by (domain, scale) and cyb_root_board already exposes both columns.
The audit queried the board WITHOUT filtering, read 0.1% sensed across the union, and declared
the root axis blind. The axis is not blind and the view is not broken — the QUERY was.
Filter by (domain, scale) before drawing any conclusion from a root board.
**A near-zero reading across a very large node set is evidence you are reading the wrong
node set.** This is the SKILL.md sensor rule applied to nodes instead of carriers.
Consequence avoided: a proposed pass over 1,642 nodes would have written ~40,000 sensor rows
against roots belonging to no passage.
